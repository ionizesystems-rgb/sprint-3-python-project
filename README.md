# TripleTen Sprint 3 Project: Data Analysis with Python

## Description
This repository will keep all of the files from my Sprint 3 project where I am completing different tasks to analyze the data of video game sales. I will work with variables, strings, lists, loops, conditionals, dictionaries, and functions to explore trends in the gaming industry.

## Data Source
The dataset contains information about some of the best-selling video games of all time. The data is provided as a Python list of lists in the precode of each task.
